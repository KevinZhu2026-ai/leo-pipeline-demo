# 卫星轨道展示系统（自研展示层）

本地离线可跑的卫星态势展示页。**不依赖任何 AGPL 代码**，素材与数据全部本地。

## 启动

双击 `start.command`（自动选端口 + 开浏览器）。或：

```bash
cd "_build/site"
python3 -m http.server 8100     # 打开 http://127.0.0.1:8100/
```

需通过 http 打开（ES 模块 + 数据 fetch 不支持 file://）。

### 星座轨迹（全对象）

左栏「星座轨迹」勾选后，为当前所有**可见对象**画出完整轨道（每条 72 个采样点，按星座着色）：

- 抽样上限 12 000 条，超出自动抽样并在标签标注（如「11 115 条轨迹（抽样 1/3）」）
- 过滤条件变化、或时间跳变超过 10 分钟时自动重建（ECEF 下轨迹会随时间漂移）
- **透明度随条数自适应**：`0.55 × (400/n)^0.6`，钳在 0.04–0.55。单独显示一个星座（几十到几百条）时清晰可辨，全编目 1.1 万条时降到 0.07 不会糊住地球
- 实测：仅星链 9 894 条，构建耗时 0.7 s，约 140 万线段顶点；软件渲染下 2 fps，GPU 环境明显更好
- 星链 53° 倾角形成的**极区空洞**在轨迹模式下清晰可见（点云模式下反而不易察觉）

### 单星覆盖范围（footprint）

控制位于**左栏「星座轨迹」下方**（常驻，不需要先选中卫星）；点「覆盖范围」后在地球上画出选中卫星的地面可见范围：

- **两种模式**（覆盖栏第二个下拉）：`单星` = 只画选中卫星；`星座` = 画左栏当前分组（solo）或选中卫星所属星座的**全部卫星**覆盖，低透明度叠加成覆盖带；上限 500 颗，超出均匀抽样并在提示里标注
- **未选中卫星时点开覆盖会自动选一颗**（优先星链 LEO 载荷），并提示已选中哪一颗；也可先用搜索框换
- 半径按几何公式：`ψ = arccos(R/(R+h)·cosε) − ε`，地面半径 = `R·ψ`
- 仰角门限可选 0° / 10° / 25° / 40°，实时重算并显示半径
- 画法：地球表面半球冠（半透明填充）+ 边界圈 + 卫星到边界的连线（覆盖锥）
- **与轨迹互斥（双向）**：开覆盖会自动关闭星座轨迹与单星轨道线；开轨迹会调用统一的 `clearCoverageVisuals()`，把单星环/锥/冠与星座模式的合并网格、轮廓线一起移除，并复位按钮高亮与提示文本
- 实测（星链 476 km 高度）：10° → 1 513 km；25° → 835 km；0° → 2 392 km

### L2 接触图（链路）

顶栏「链路」打开面板。链路分五色：**同轨 / 异轨 / 缝合线**（星间三类）+ **馈电**（琥珀）+ **用户**（绿），太阳规避踢掉的链路单列灰色。图例常驻面板内。

#### 地面段：用户链路与馈电链路

- **选中站点 ↔ 可见卫星**：以 10° 仰角为门限连出可见 LEO/MEO（上限 240 条）。站点来自两套数据：
  - **ITU 已申报馈电站**（39 座，`data/feeder.json.gz`）：Iridium 35、OneWeb 2、Starlink 1、中国星网 1，带频段与收妥日期。选中后站点标记与覆盖圈转为琥珀色，链路按"馈电"计
  - **演示点位**（8 个中国城市）：用于"用户链路"演示，绿色；也可自定义经纬度
- **全星座馈电站馈电**：对每座馈电站，连到其所属星座内当前可见、距离最近的 2 颗卫星（上限受 12 000 段缓冲约束）。这一层用来回答"某星座此刻有几座关口站真的在服务"
- 站点覆盖圈的高度取**该星座中位轨道高度**（`CON_ALT`，由编目实时计算），不再假设固定 550 km
- 数据现实：ITU 申报只登记关口站/典型地球站，**不含运营商商用网关全量**。所以星链只有 1 座、千帆为 0——面板会如实显示"可见馈电站 N/39"，这个数字本身就是结论

#### 空间段：星间链路三类拓扑

依据《低轨星座管道化展示仿真_星间链路调研》§3–§6 建模，不再是"按距离找近邻"的启发式：

| 类型 | 判据 | 物理特征 | 颜色 |
|---|---|---|---|
| 同轨 intra-plane | 同一轨道面内按纬度幅角 u 排序成环，前后各一条 | 距离恒定，**运行期不断链** | `#4fb6ff` |
| 异轨 inter-plane | RAAN 环上相邻面、按 u 最近邻配对（两方向各一次） | 距离随纬度伸缩 | `#7dd3fc` |
| 缝合线 seam | RAAN 环**最大间隙**两侧的那一对轨道面 | 两侧相对运动反向，**链路周期性中断** | `#ff9ecd` |

- **轨道面识别**：先按「倾角取整 + 高度壳（20 km）」分组（不同壳层的 RAAN 集合互不相干），组内按 RAAN 排序、以**自适应间隔阈值** `min(中位间隔×0.5, 8°)` 断簇。不用固定角度硬分桶——真实 TLE 的 RAAN 有拟合噪声，3° 硬桶会把 Iridium 的 6 个面切成 28 块，异轨配对就会连到"假的相邻面"（这是一次实测踩坑）
- **终端度数上限**：同轨优先占 2 条，余量给异轨；上限取 `min(系统配置, 面板设定)`。系统配置：Iridium / Starlink / Kuiper / Telesat 4 条，**OneWeb 与 Globalstar 为 0（无星间链路设计）**，面板会明确标注"无星间链路设计：OneWeb"
- **太阳规避**：勾选后按光学终端 3° 太阳禁区剔除链路（视线方向与太阳方向夹角 < 3°），灰色单列，可直接观察"日落断链"
- **抽样绘制**：链路总量可达 1.5 万条，全画会糊成毛球。绘制按配额等间隔抽样（>3 000 节点时同轨 1 200 / 异轨 800 / 缝合 500），**统计口径仍是真实总数**，面板注明"画面抽样绘制 2 104 / 15 385 条"
- 每 1 秒重算；实测星链全量（9 894 节点）单次 24–36 ms，Iridium 3 ms

### 过顶预测（多站 / 多星）

顶栏「过顶预测」打开右侧抽屉，三种模式：

| 模式 | 计算对象 | 递推 | 用途 |
|---|---|---|---|
| 选中卫星 × 全部馈电站 | 1 星 × 本星座全部馈电站（无则 39 座全上） | SGP4，30 s 步长 | 该星能被几座关口站接管、"任一站可见"的时间占比 |
| 指定站点 × 星座 | 1 站 × 该星座可见 LEO（上限 200 颗） | 二体递推，60 s 步长 | 单站对整星座的过境频次、峰值同时可见、覆盖率 |
| 选中卫星 × 指定站点 | 1 星 × 1 站 | SGP4，30 s 步长 | 单链路精细窗口 |

- 时间窗 6/12/24/48 h，仰角门限 0°/10°/25°/40°
- 四张指标卡：**过境窗口数 / 时间覆盖率 / 最长断链 / 峰值同时可见**（多站模式改为"合并可见时长"）
- 明细表：起止时刻、时长、最高仰角、窗口条形图；按起始时间排序，上限 400 行
- 底部给出**结论句**而非只给表：覆盖率 ≈100% 时提示"瓶颈不在可见性，而在星上资源与波束调度"；覆盖率偏低且为多站模式时提示"ITU 申报站址稀疏，并非系统能力上限"
- 分片计算（每片 ≤22 ms 让出主线程），站点×星座 787 次过境约 2 s 出结果
- 语义边界写在面板底部：**几何可见性**预测，不含链路预算、雨衰、波束调度与星上资源约束

## 精度约定

- **点云**：开普勒二体近似递推（20 Hz 更新），保证 3 万+ 对象流畅
- **选中目标 / 过境计算 / 单星×多站预测**：satellite.js SGP4 精确递推
- **站点×星座预测**：二体近似（60 s 步长），仅用于统计量，不用于单窗口精确时刻
- **轨道面识别**：用 TLE 的 RAAN/倾角/高度壳做聚类，不做数值积分；星座面漂移（J2）在编目时效内不重算
- 顶栏「编目」标签显示主体编目的中位纪元与实际年龄，不掩盖数据时效

## 数据刷新

```bash
python _build/refresh_catalog.py --web     # 拉 CelesTrak 分组 → 合并 → 重建 web 数据
python _build/fetch_itu_earth_stations.py  # 拉 ITU 地球站库（active 子库）
python _build/build_feeder_stations.py     # 地球站 → 按星座归并的馈电站清单
python _build/build_web_feeder.py          # 馈电站 → site/data/feeder.json.gz
```

已知限制：CelesTrak 对同一 IP 的 `active` / `starlink` 大组有下载间隔限制，命中时返回 403，
脚本会跳过该组并在输出中标注，其余组照常合并。当前 StarLink 组仍为 2026-03-09 快照。
